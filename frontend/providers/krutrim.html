The 8 Standard Evaluation Criteria

01

What it does, and for whom

What it does, and for whom: Cloud AI computing and foundational model platform offering Indic LLM inference, Speech-to-Text, and Text-to-Speech APIs. Targets developers and enterprises seeking an all-in-one Indian cloud platform spanning GPU compute, storage, and multilingual model endpoints.
02

Price in India (INR / GST / Commitments)

Price in India: Pay-as-you-go in INR. Krutrim Pro model: ● ₹0.15 / 1k tokens (~₹150 / 1M tokens) · https://cloud.olakrutrim.com/pricing · checked 23 November 2026. ASR: ● ₹0.35 / audio min · https://cloud.olakrutrim.com/ · checked 23 November 2026. Prices subject to 18% GST. Full Indian GST tax invoices issued.
03

Indian language support

Indian language support: ● 22 Indian languages for text processing; 10 languages for speech synthesis and voice bots.
04

Data location and privacy

Data location and privacy: ● Hosted in Krutrim's proprietary and collocated data centers in India. Data residency guaranteed within national borders.
05

Fit with tools you already use

Fit with tools you already use: OpenAI-compatible REST API `/v1/chat/completions` endpoint, allowing minimal code modification to switch from existing OpenAI or Anthropic SDK wrappers.
06

Setup and support in India

Setup and support in India: Instant developer signup with Indian mobile number (OTP verification). Paid wallet recharge via UPI, RuPay, and Indian credit/debit cards.
07

Contract and exit terms

Contract and exit: Prepaid credit balance with pay-per-token deductions. OpenAI-compatible API design ensures negligible switching cost.
08

Evidence in practice

Evidence in practice: Integrated into Ola consumer apps (Ola Cabs customer support, Krutrim AI Assistant). Reviewer tests verify high token throughput on Hindi and Tamil, with competitive per-token cost.
